Muffin User Guide

Turn your Google Sheet into a cozy personal finance dashboard. Installable as a PWA — live balances and KPIs always load from your sheet over the network.

Getting started in 3 steps

New accounts get a short first-run tour after linking a sheet. You can replay it anytime from the in-app User Guide.

Sign in with Google, then paste an existing Sheet URL/ID or tap Create a sheet for me, choose a workbook name, and create a pre-formatted 3-tab workbook. Tap the sheet title in the app header later to change or unlink.
Tap + in the bottom navigation to add Income, Expense, or Investment. Edit or delete from the Ledger. You can also edit the Google Sheet directly — Muffin reloads when you open or refresh the app.
Tap any KPI tile on Home for lists, pie breakdowns, or monthly line trends with crosshairs and month-over-month deltas. Open More Details for lifetime totals and Provident Fund.

Tabs & features

Four main tabs sit in the floating bottom navigation, plus a center + button to add transactions.

Home

Personalized greeting, live KPIs (Liquid cash, Net worth, Month overview, Avg monthly savings with % rate badge), and Investment Breakup (top 3 chips — tap for full pie). Tap any card for interactive charts or lists. Scroll down for Provident Fund, lifetime totals, and growth metrics.

Insights

Unified analytics hub with 3 sub-views: Trends (month-by-month bar charts with drill-down to Ledger), Categories (SVG donut ring + ranked expense list), and Planner (what-if scenario builder with budget sliders).

Ledger

Searchable timeline with date-grouped headers ("Today", "Yesterday"), category icons, and an inline QuickAdd strip on top for instant 1-line expense/income logging. Tap a row for full details or to edit/delete.

Settings

Full customization hub: Account details with linked sheet indicator, live 8-Theme picker (4 light + 4 dark), 7 Typography styles, Mask Amounts toggle, Starting Balances (Recipe), Guides, and PWA Install.

Tip: Investments reduce liquid cash but are not expenses. Provident Fund rows are tracked separately and do not count toward net worth or the investment breakup pie.

Adding & managing transactions

Add entries in-app using the QuickAdd strip or the + modal, or directly in Google Sheets — both stay in sync automatically.

At the top of the Ledger tab, a single-line QuickAdd strip allows instant logging: switch between Expense/Income, tap recent category chips, type the amount (or math expressions), and submit in one tap without opening any modal.
Tap the glowing + button in the center of the floating bottom navigation. Choose Income, Expense, or Investment. Fill in the date, category, amount, and an optional comment. For investments, select or type an Investment Type (e.g., Mutual Fund, Fixed Deposit).
The top frequent categories appear as one-tap chips. The amount field supports full BODMAS arithmetic and percent math (e.g. 1000 * 18% for tax/GST) with instant live result evaluation.
On the Ledger tab, tap any transaction row to open its details. From there you can edit (pre-filled form) or delete (with a confirmation prompt). Changes are written directly to your Google Sheet using stable row IDs.
To log PF contributions, add them as regular Investment rows and set the Investment Type (or Category) to one of: Provident Fund, PF, EPF, or PPF. These rows appear in the Ledger, but are excluded from net worth and breakup charts. PF surfaces only on Home as a dedicated Provident Fund total card.

Investment tab

Columns: Id (optional), Date, Category, Amount, Investment Type, Comment

Sample: 2026-08-05, SIP, 10000, Mutual Fund, Nifty Index

Recipe tab

Opening balance and starting investment portfolio configuration synced across your devices.

Rules tab

Recurring rule schedules, automated SIPs, and cycle tracking with dedicated columns.

Column rules: Prefer dates as YYYY-MM-DD (DD/MM/YYYY also works). Amounts should be digits only (e.g. 15000). Keep the header row — the app skips it. App-created sheets include a stable Id column for safer edit/delete.

Install Muffin as an app

Muffin is a Progressive Web App (PWA) — you can install it on your phone or desktop for a native-like experience.

  1. Open the ⚙️ settings menu and tap Download App.
  2. If the native install banner appears, tap Install.
  3. Otherwise open Chrome's ⋮ menu and choose Install app (preferred). Prefer Install over Add to Home screen so Android packages Muffin as a full PWA (standalone, themed status bar), not a browser shortcut.
  4. Muffin opens fullscreen with a status bar that matches your theme canvas.
  1. Open Muffin in Safari (not Chrome — iOS requires Safari for PWA install).
  2. Tap the Share button (box with up arrow) at the bottom of the screen.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the top-right corner.
  1. Open Muffin in Chrome or Edge.
  2. Look for the Install icon (⊕) in the address bar, or use the ⚙️ settings menu → Download App.
  3. Click Install in the prompt.
  4. Muffin opens in its own window without browser chrome.
Note: The PWA shell loads offline, but live financial data (KPIs, ledger) requires a network connection to reach your Netlify backend and Google Sheets.
