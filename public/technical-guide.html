Technical Solution & Architecture

Developer specs, data flows, serverless API contracts, and runtime metrics engine documentation.

💻 Core Technology Stack

Frontend Core

React 19 + TypeScript + Vite 6

Typed React SPA built with Vite for fast HMR dev server and optimized production bundles.

Styling & Animation

Tailwind CSS 3 + Framer Motion

6 muffin theme tokens (`data-theme`), soft spring micro-interactions, layout pills, and portaled sheets.

Backend Serverless

Netlify Functions + Netlify Blobs

Serverless Google Sheets API proxy keeping OAuth secrets secure; Blobs stores per-user sheet links & Recipe balances.

PWA Capabilities

Vite PWA + Workbox

Standalone PWA manifest, custom icons, and automatic service worker asset precaching.

AI & Agent Tooling

Antigravity, Cursor & GitHub Copilot

Autonomous agentic pair programming by Antigravity (Google DeepMind team), Cursor AI IDE, and Copilot.

🔄 Runtime Architecture & Data Flow

Data moves through a secure serverless proxy architecture:

1. React SPA (Browser)
   └── GET /.netlify/functions/transactions
       └── Netlify Function (Auth verification)
           └── Google Sheets API (OAuth2Client)
               └── Read/Write Income, Expense, Investment tabs

2. Metric Engine (Client-Side)
   └── buildFinancialMetrics(transactions)
       ├── Calculates Net Worth, Liquid Savings & Investments
       └── Isolate Provident Fund rows to dedicated More Details card

3. Recipe & User Store
   └── Netlify Blobs (store: muffin-users)
       └── Encrypted httpOnly session cookie for OAuth refresh tokens

🔑 Required Environment Variables

Configured in Netlify Site Settings / local .env file:

Variable Name Description
GOOGLE_CLIENT_ID Google OAuth Web Client ID from Google Cloud Console
GOOGLE_CLIENT_SECRET Google OAuth Web Client Secret
GOOGLE_REDIRECT_URI OAuth redirect URI (e.g. https://YOUR-SITE.netlify.app/.netlify/functions/auth-callback)
SESSION_SECRET Random secret string used for httpOnly session cookie encryption

🧮 Metrics Engine Specifications

Mathematical calculations implemented in src/lib/metrics.ts:

investmentBalance = initialInvestments + SUM(countedInvestment)
trackedLiquid     = SUM(income) - SUM(expense) - SUM(countedInvestment)
liquidBalance     = openingBalance + trackedLiquid
netWorth          = investmentBalance + liquidBalance
providentFund     = SUM(PF / EPF / PPF rows) [Isolated on More Details]
